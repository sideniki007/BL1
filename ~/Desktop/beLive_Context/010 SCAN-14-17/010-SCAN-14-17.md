## SCAN-14: `startPractice` — `currentRate` всегда 0.8

### 🔍 Что нашли

| Строка | Файл | Код |
|--------|------|-----|
| 217 | `practice-session.store.ts` | `currentRate: 0.8` |

`startPractice()` **жестко зашивает** `currentRate: 0.8` для ВСЕХ сценариев, независимо от `scenario.meta.startRate`.

### 📊 Таблица несоответствий

| Сценарий | meta.startRate | Реальная скорость | Store.currentRate | Баг? |
|----------|---------------|-------------------|-------------------|------|
| bpm-ramp | — (не указан, default engine) | 1.0 (engine до старта) | 0.8 | ❓ Не влияет (actions задают rate) |
| focus-mix | 1.0 | 1.0 | 0.8 | 🔴 **ДА** — store врёт |
| section-breakdown | 1.0 | 1.0 | 0.8 | 🔴 **ДА** — store врёт |

### 🧬 Корневая причина

`startPractice` не читает `scenario.meta.startRate`. Она просто ставит 0.8 для всех.

### 🔧 Фикс

Прочитать `startRate` из сценария:
```typescript
const scenario = getScenario(scenarioId as PracticeScenarioId);
const startRate = scenario?.meta?.startRate ?? 0.8;
// ...
set({
  // ...
  currentRate: startRate,  // вместо 0.8
});
```

## SCAN-16: Стемы могут быть выключены

### 🔍 Что нашли

| Файл | Строка | Что |
|------|--------|-----|
| `stem.store.ts` | 41, 132 | `stemsEnabled: boolean` — default `false` |
| `stem.store.ts` | 194 | `clearStems` → `stemsEnabled: false` |
| `stem.store.ts` | 163 | `initStems` → preserves existing `stemsEnabled` |
| `bridge/audio.bridge.ts` | 184 | `if (st.stemsEnabled)` — проверка при синке объёмов |

### 🔬 executeSetStemVolume (ai-tools.ts:598)

```typescript
async function executeSetStemVolume(args): Promise<ToolCallResult> {
  const stemId = normalizeStemId(String(args.stemId || ''));
  const volume = Math.max(0, Math.min(1, Number(args.volume ?? 0)));
  const ae = (window as any).audioEngine;
  if (ae?.setStemVolume) ae.setStemVolume(stemId, volume);
  useStemStore.getState().setStemVolume(stemId, volume);
  // ... success message ...
}
```

**Проблемы:**
1. **Нет проверки `stemsEnabled`** — tool выполняется даже если стемы выключены
2. **Нет включения стемов** — `executeSetStemVolume` не переключает `stemsEnabled`
3. **Нет tool для включения стемов** — нет `enable_stems` или `set_stems_enabled` в ai-tools.ts
4. Если `stemsEnabled=false`, `ae.setStemVolume(stemId, volume)` может быть no-op (движок не создал стем-ноды)

### ⚠️ Последствия для focus-mix

startActions focus-mix не включает стемы. Если у пользователя `stemsEnabled=false`:
- `set_stem_volume(instrumental=1, vocals=0)` — не сработает
- Все 4 круга будут звучать одинаково (как полный микс)
- Пользователь не увидит эффекта "только минус" / "только вокал"

### 🔧 Фикс

1. **Добавить tool** `enable_stems` в ai-tools.ts → `set({ stemsEnabled: true })`
2. **Добавить** `{ tool: 'enable_stems' }` в startActions focus-mix
3. **Или** пусть `executeSetStemVolume` сам включает стемы (но это side effect — хуже)
